# המסלול – אתר כושר קרבי

אתר סטטי (HTML, CSS ו-JavaScript בלבד, בלי תלויות ובלי build) שמחליף את האתר הקיים ב-hamaslul.co.il.
המטרה: מבקר מבין תוך שלוש שניות מה המסלול מציע, ומגיע לתיאום אימון ניסיון בכמה לחיצות.

## הרצה
פותחים את `index.html` בדפדפן, או מעלים ל-GitHub Pages / Netlify / Vercel (Settings → Pages → Deploy from branch → `main` / root).

## מבנה
```
index.html      התוכן והמבנה (RTL, עברית)
css/styles.css  עיצוב: צבעים, טיפוגרפיה, רספונסיביות
js/main.js      צוותים, חיפוש וסינון, אנימציות, טופס
assets/photos/  מקום לצילומים אמיתיים (ראו למטה)
```

## עיצוב
- צבע ראשי: ירוק זית `#2b3a27`. צבע משני: חול `#e7dcc2`. כתום `#ff6a2b` רק לכפתורי פעולה.
- פונטים: Rubik לכותרות, Heebo לטקסט (Google Fonts). טקסט בגודל 17px ומעלה.
- אנימציות קלות: כניסת ההירו ושרטוט המסלול, ספירת מספרים, חשיפה בגלילה. הכול מכבד `prefers-reduced-motion`.

## עריכת תוכן
- **צוותים** (עיר, מקום, ימים, מדריך, טלפון): מערך `TEAMS` בראש `js/main.js`.
- **יחידות**: מערך `UNITS` באותו קובץ.
- **מספר הוואטסאפ הראשי**: `WA_MAIN` בראש `js/main.js`.
- **נתוני ההצלחה** (95%, 3,500 ועוד): בלוק `.stats` ב-`index.html`. כרגע מסומנים כ"נתוני 2024".

## מה עוד צריך להשלים
1. **קישור הרשמה ותשלום.** כרגע ההרשמה עוברת בוואטסאפ למדריך או למספר הראשי. אם יש עמוד הרשמה ותשלום, כדאי לחבר אותו לכפתור בשלב 3 ובכותרת.
2. **צילומים אמיתיים.** האתר עובד בלי תמונות. כדאי להוסיף ל-`assets/photos/` צילומי אימון, גיבוש וצוות (דחוסים, עד כ-200KB לתמונה) ולשלב אותם בהירו ובסקשן הסיפורים.
3. **לוגו.** כרגע סימן וכיתוב בקוד (SVG). אפשר להחליף בלוגו המקורי.
4. **מחירים.** מומלץ להוסיף שאלה בשאלות הנפוצות על עלות ותשלום.
